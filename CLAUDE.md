# wiz-control-app

Finds WiZ bulbs on the local network, shows their state, and changes brightness, white and color. Monorepo: Python server (uv workspace), Svelte + TypeScript frontend (pnpm), Docusaurus docs site.

## Layout

| Path | What it is |
| --- | --- |
| `packages/wiz-protocol-py` | `wiz_protocol`: async UDP client and discovery for WiZ bulbs. `wiz_protocol.testing.FakeBulb` is a fake bulb for tests |
| `apps/server-py` | `wiz_server`: domain, service layer, adapters, FastAPI entrypoint. Script `wiz-server` |
| `apps/web-ts` | Svelte SPA (pnpm package `web`). Tailwind + shadcn-svelte, typed client from the OpenAPI schema |
| `architecture/decisions/` | ADRs |
| `architecture/journal/` | The author's working journal |
| `architecture/site` | Docusaurus site for decisions and journal. Not an app |

- Every folder in `apps/` and `packages/` ends in `-py` (uv member) or `-ts` (pnpm package). No suffix means neither workspace.
- `.github/workflows/docs.yml` deploys the site to GitHub Pages on push to `main`. `baseUrl` is `/wiz-control-app/`.

## Tooling

- mise pins python, uv, node, and pnpm in `mise.toml`. Nothing is installed globally, uv included.
- The root `pyproject.toml` is a virtual uv root. Every Python member is in its `dev` group, so plain `uv sync` installs all of them.
- A new Python member must be added to both `[tool.uv.sources]` and the `dev` group in the root `pyproject.toml`.
- pytest runs with `--import-mode=importlib`. Shared server test doubles live in `apps/server-py/tests/server_fakes.py`.

## Rules

Repo-wide rules are in `.claude/rules/`: layout and layers, commits, journal, architecture docs.

- The journal is dictated by the author. Never write an entry or a finding on your own.
- Not every bulb has color. Capabilities come from the bulb: `moduleName` containing `RGB`, `cctRange`, `minDimLevel`.
- Bulbs answer `success` to `setPilot` values they ignore, such as dimming below `minDimLevel`. Validate in the domain.
- `apps/web-ts/src/lib/api/openapi.json` and `schema.d.ts` are generated by `pnpm gen:api`. Regenerate them after any API change, never edit by hand.
- The API returns `rgb` as `{r, g, b}`, not a tuple: openapi-typescript types a tuple two different ways and they clash.

## Network gotchas

- Replies to a UDP broadcast never arrive on this host, but unicast works. Likely ufw dropping them: the reply comes from the bulb's IP, not the broadcast IP.
- So discovery sweeps the subnet host by host. Set `WIZ_TARGETS` to the LAN subnet, for example `192.168.2.0/24`.
- `WIZ_TARGETS` takes a comma list of IPs, broadcast addresses, or CIDR subnets. Default is `255.255.255.255`, which finds nothing here.

## Running

| Command | What it does |
| --- | --- |
| `mise install` | Install the pinned tools |
| `uv sync` / `pnpm install` | Install Python / Node deps |
| `uv run pytest` | Unit, integration (fake bulbs) and e2e tests. No real bulbs needed |
| `WIZ_SUBNET=192.168.2.0/24 uv run pytest -m integration` | Read-only checks against real bulbs |
| `uv run ruff check . && uv run pyright` | Lint and type-check Python |
| `WIZ_TARGETS=192.168.2.0/24 uv run wiz-server` | API on `127.0.0.1:8000` (`WIZ_HOST`, `WIZ_PORT` to change) |
| `pnpm dev:web` | Frontend on `:5173`, proxies `/api` to `WIZ_API_URL` or `127.0.0.1:8000` |
| `pnpm check:web` / `pnpm build:web` | svelte-check / production build |
| `pnpm gen:api` | Regenerate the OpenAPI schema and TS types |
| `pnpm dev:docs` | Docs site |
